PSSO Forge helps IT administrators create and inspect macOS Platform SSO Settings
Catalog profiles for Microsoft Intune.

Requirements: macOS 26 or later. The app interface is English. Creating and
verifying local files does not require an Intune sign-in. Deploying exported
profiles separately requires the appropriate tenant permissions and testing.

Before contacting support:

- Note the version and build shown in About.
- Describe the steps, expected result and exact error message.
- Use a sanitized sample profile. Remove secrets, tenant details, personal names
  and organization-specific information that is not necessary to reproduce the issue.
- A compatibility notice describes assessed settings, not a guarantee that a
  deployed profile will work on every device.
- Unavailable tip buttons do not block profile creation or verification.
- If a tip fails, note its name and the displayed message. Do not send payment
  details or Apple Account credentials. Billing and refund requests should use
  Apple's purchase-support channels.
- A generated PowerShell command can contain a tenant ID and local file path;
  sanitize those as well as the JSON before sending an example.

Contact: **pssoforge@e-nahum.net**.
Never send passwords, access tokens, certificates or unredacted production profiles.
Only attach files needed to reproduce the issue. Sending a support email is
optional; the app does not automatically send profile files.

Read the [privacy policy](/en/privacy/) for information about data handling.
